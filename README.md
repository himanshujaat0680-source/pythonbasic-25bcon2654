# Python Basic Programs 

This repository contains simple Python programs for beginners to learn and practice fundamental programming concepts. Each program demonstrates common operations using easy-to-understand code.

##  Programs Included

| File Name | Description |
|---|---|
| `dictionary.py` | Demonstrates dictionary operations such as accessing, adding, updating, deleting, looping, and counting words. |
| `factorial.py` | Calculates the factorial of a number using loops, recursion, and Python's `math` module. |
| `fibonacci.py` | Generates the Fibonacci series using a loop, recursion, and a generator. |
| `list.py` | Demonstrates list operations such as adding, removing, sorting, slicing, and list comprehension. |
| `multiplication.py` | Generates the multiplication table of a number and a complete multiplication grid. |

##  Features

- Beginner-friendly Python code
- Examples of functions and loops
- List and dictionary operations
- Recursion and generators
- Input validation and error handling
- Practical examples for learning Python fundamentals

##  Requirements

- Python 3.x
- Any code editor, such as VS Code, or a Python IDE

No external libraries are required.

##  How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or your terminal.
3. Run any Python file using the following commands.

```bash
python dictionary.py
python factorial.py
python fibonacci.py
python list.py
python multiplication.py
```

On some systems, use `python3` instead of `python`.

##  Learning Objectives

By exploring these programs, beginners can practice:

- Variables, data types, and user input
- Conditional statements and loops
- Functions and recursion
- Lists and dictionaries
- List and dictionary comprehensions
- Generators and built-in Python modules

##  Purpose

This repository is created for Python beginners, programming practice, and students who want to strengthen their basic Python programming skills.
